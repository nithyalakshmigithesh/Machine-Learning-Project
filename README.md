# Machine-Learning-Project
Star Review Rating Prediction using Machine Learning

## Overview
This project predicts user star ratings (1–5) based on review text using Machine Learning models.

##  Models Used
- Logistic Regression
- Decision Tree
- XGBoost

## Techniques
- TF-IDF Vectorization
- Label Encoding
- Train-Test Split

##  Features
- Compare multiple ML models
- Predict ratings from user input
- Interactive UI using Gradio
